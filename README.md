# Code Craft repo for Frontend Skill practice

This repository is created for practicing and improving real-world frontend development skills using React.js, Next.js, modern JavaScript, reusable components, routing, hooks, API integration, and feature-based development.

The goal of this repository is to build practical features step by step and maintain them in a clean, scalable, and production-ready structure.

## Purpose

- Practice real-world frontend development concepts
- Improve component-based development skills
- Build reusable and scalable UI components
- Understand static and dynamic routing
- Practice React hooks and custom hooks
- Improve Next.js project structure
- Build eCommerce and dashboard-based features
- Follow clean code and best practices
